# "Who is Doctor Doom, and why is Iron Man playing him?": pitch v1 (2026-11-24)

Format: **long-form, 16:9 (1920×1080), 60 fps, ~9.5 min**, English narration, chapters.
Target upload: **Dec 12–15, 2026** (Avengers: Doomsday premieres Dec 14, US release Dec 18).
Final trailer dropped Nov 23, so search interest is rising now.

## Length

9–10 min is right. It's past the 8-minute mark that allows mid-roll ads, short enough to keep a
new channel's audience, and about 1,400 narration words at ~150 wpm. Longer wouldn't add value
on this deadline: build time grows with every minute.

## Long-form pacing (vs the Shorts)

Shorts: ~1.8 s mean shot. Long-form documentary pace: **~3.5–5 s mean, ~130 shots**, held
dialogue-free scenes with slow camera moves, 2D inserts (headlines, timeline, chapter cards).
Pokhran: 58 shots / 162 s in about 3 days. This: ~130 shots, so **~8–10 working days**. That fits
the Dec 12–15 target if the script is approved by ~Nov 27.

## HyperFrames (HeyGen, open source): feasibility

What it is: HTML/CSS/GSAP/Lottie/Three.js compositions rendered frame by frame in headless Chrome
→ MP4/MOV/WebM/GIF/PNG sequence. Apache 2.0, free local rendering, Node ≥ 22 + FFmpeg (we have
Node 22.13.1, FFmpeg 9.0.2). Agent skills for Claude Code.

**Where it fits:** the 2D layer that long-form needs and the Shorts didn't: chapter cards,
lower thirds, a recreated Variety/Deadline headline, the timeline (1962 → 2015 → 2026),
comic-cover inserts, maps, captions. It does **not** replace Godot (the toon actors and the 3D
world); our in-world reveals and counters stay in Godot.

**How to wire it in:** render the overlays separately (PNG sequence with alpha at 1920×1080) and
composite them in the existing ffmpeg `finish` step. Don't feed our Godot MP4 through Chrome:
frame accuracy of embedded video isn't documented, and Chrome would re-encode our 60 fps frames.

**Unknowns to test in a 1-hour spike:** 60 fps output, alpha output, render speed at 1080p,
whether it runs on Windows (the CLI's Windows support isn't stated), and telemetry.
**Don't use:** HeyGen cloud rendering, `share`, or the Studio's hosted AI models (rule 9: no
generative services; renders stay local).

**Download needed (asking first):** the `hyperframes` npm package + Puppeteer's headless Chrome
(~150–200 MB), into a scratch folder, not the repo.
